## Commit Message Conventions

All commits use `[prefix]` format:

| Prefix | Use for |
|---|---|
| `[ocw]` | OCW session logs, problem sets |
| `[read]` | Adler worksheets, reading notes |
| `[log]` | Monthly reading logs, weekly logs |
| `[docs]` | Strategic documents updated |
| `[tools]` | Tool workflow updates |
| `[reflect]` | Course or phase reflections |
| `[lit]` | Literature review, annotated bibliography |
| `[fix]` | Corrections to any document |

**Examples:**
```
[ocw] 6.1200J session log - lecture 1 propositions and logic
[read] Adler worksheet - guzdial-2015-learner-centered
[log] Reading log - May 2026
[reflect] 6.1200J complete - course reflection
```
